# Aciron Launcher

Лаунчер Minecraft, в котором сборка с модами, аккаунт, друзья и гардероб живут в
одном окне — без вкладок браузера и папок с архивами.

**Сайт:** [aciron.pro](https://aciron.pro) ·
**Скачать:** [последний релиз](https://github.com/Acizecu/aciron-launcher/releases/latest) ·
Windows 10/11, x64

> Стадия — бета. Лаунчером уже пользуются каждый день, но что-то ещё меняется.

## Что умеет

**Сборки.** Своя сборка на любой версии игры: Fabric, Quilt, Forge, NeoForge.
Моды, ресурспаки и шейдеры ставятся поиском прямо в лаунчере — Modrinth,
CurseForge, FTB. Готовую сборку можно отдать другу одним файлом `.acpack`, а
сборки из других лаунчеров — забрать импортом.

**Запуск.** Java подбирается сама, память и аргументы — в настройках сборки.
Живая консоль игры с уровнями, фильтром и поиском. Одну сборку можно открыть в
двух окнах, у второго свой профиль.

**Аккаунты.** Офлайн-имя, лицензия Microsoft и единый аккаунт Aciron ID.
Лицензия привязывается рукопожатием с Mojang — постоянный доступ к игровому
аккаунту, никто не получает ваши токены.

**Гардероб.** Библиотека скинов и плащей, образы целиком, примерка на 3D-модели.
Надетое устанавливаются сразу на лицензию.

**Друзья.** Список друзей, переписки. Все в лаунчере.

**Оформление.** Готовые темы и своя: акцент, фон, текст, любой отдельный цвет.
Тему можно сохранить и отдать другу кодом.

## Собрать из исходников

Нужны [Node.js](https://nodejs.org) 20+, [Rust](https://rustup.rs) (stable) и
[зависимости Tauri 2](https://v2.tauri.app/start/prerequisites/) — на Windows это
WebView2 и Build Tools для C++.

```bash
npm install
npm run tauri dev # запуск в режиме разработки
npm run tauri:build # установщики в src-tauri/target/release/bundle
```

Часть возможностей смотрит в сервис Aciron ID (аккаунты, друзья, гардероб) и в
прокси каталога CurseForge. Адреса и ключи задаются переменными окружения на
сборке — `ACIRON_ID_URL`, `ACIRON_CF_PROXY_URL`, `ACIRON_CLIENT_KEY`,
`ACIRON_PROXY_TOKEN`, `ACIRON_MS_CLIENT_ID`. Без них лаунчер собирается и
запускается, но сетевые разделы, завязанные на эти сервисы, работать не будут:
свои ключи и свой сервер придётся поднять самому.

## Как устроено

Оболочка — [Tauri 2](https://v2.tauri.app): интерфейс на React 19 + TypeScript +
Tailwind, вся работа с файлами, сетью и процессом игры — на Rust в `src-tauri/src`.

| | |
|---|---|
| `src/` | экраны, состояние, темы, словари языков |
| `src-tauri/src/launcher.rs` | сборка classpath, аргументы, запуск игры |
| `src-tauri/src/builds.rs`, `pack.rs`, `importer.rs` | сборки, `.acpack`, импорт |
| `src-tauri/src/modrinth.rs`, `curseforge.rs`, `ftb.rs` | каталоги модов |
| `src-tauri/src/accounts.rs`, `microsoft.rs`, `aciron.rs`, `mojang.rs` | аккаунты и облик |
| `src-tauri/src/social.rs`, `chat.rs`, `realtime.rs`, `presence.rs` | друзья, переписка, статусы |

Публичный репозиторий — экспорт исходника без комментариев и без служебных
файлов; ключей и токенов в нём нет и не бывает.

Код под [лицензией MIT](LICENSE) — форкать, менять, собирать своё и даже
продавать можно. Условия простые и невыдуманные, они прямо из лицензии и из
обычной вежливости:

**Обязательно**

- Оставить файл `LICENSE` и строку копирайта `Copyright (c) 2026 Aciron` — в
  исходниках форка и в том, что вы раздаёте людям.
- Указать, что это форк Aciron Launcher, со ссылкой на оригинал
  ([aciron.pro](https://aciron.pro) или этот репозиторий). Достаточно строки в

- Заметные изменения — обозначить как свои, чтобы за чужие правки не отвечали мы.

**Нельзя**

- Выдавать форк за оригинал: имя «Aciron», логотип, иконки, домен `aciron.pro`,
  оформление страниц и установщика — это опознавательные знаки проекта, а не
  часть кода под MIT. Назовите форк своим именем и нарисуйте свою иконку.
- Убирать авторство — из README, из интерфейса, из истории коммитов.
- Ходить в сервисы Aciron (аккаунты, друзья, гардероб, прокси CurseForge) от
  имени форка. Это чужая инфраструктура и чужие ключи: поднимайте свою.
- Подписывать сборки форка ключом обновлений Aciron — своих сборок это и не
  касается, ключ у нас, но на всякий случай: чужие обновления в наш канал
  подсунуть нельзя, и не надо.

Если сомневаетесь, можно ли — спросите на [aciron.pro](https://aciron.pro).
Отвечаем быстро.
