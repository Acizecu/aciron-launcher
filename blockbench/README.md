# Риг игрока для анимаций

Модели для Blockbench, по которым лаунчер рисует фигурку в гардеробе.
Кости, иерархия и точки опоры здесь и в рендере
(`src/components/wardrobe/playerModel.ts`) совпадают один в один — анимация,
сделанная на этом риге, ложится на фигурку как есть.

- `aciron_player.geo.json` — обычные руки (Steve, 4 пикселя)
- `aciron_player_slim.geo.json` — тонкие руки (Alex, 3 пикселя)

## Как открыть

Blockbench → **File → Open Model** → выбрать `.geo.json` (формат Bedrock Model).
Текстуру подключить своим скином 64×64 (Textures → +).

## Кости и шарниры

| Кость | Родитель | Шарнир | Что вращает |
|---|---|---|---|
| `Main` | — | `0, 0, 0` | вся фигурка |
| `Body` | `Main` | `0, 12, 0` | корпус (голова, руки и плащ — его дети) |
| `Head` | `Body` | `0, 24, 0` | голова, шея |
| `RightArm` | `Body` | `-4, 23, 0` | правая рука, плечо |
| `LeftArm` | `Body` | `4, 23, 0` | левая рука, плечо |
| `RightLeg` | `Main` | `-1.9, 12, 0` | правая нога, бедро |
| `LeftLeg` | `Main` | `1.9, 12, 0` | левая нога, бедро |
| `Cape` | `Body` | `0, 24, 2` | плащ — **только в рендере**, в модели его нет |

Ноги стоят на ±1.9, а не ±2, чтобы не мерцали друг о друга.

Плащ рендер добавляет сам, отдельной текстурой 64×32. Хотите его анимировать —
заведите в Blockbench кость с именем ровно `Cape` и шарниром `[0, 24, 2]`,
рендер её подхватит.

## Анимации

Blockbench → **Animate** → создать анимацию → **File → Export → Animation (.json)**.
Получится bedrock `.animation.json` — именно его читает
`src/components/wardrobe/animation.ts`: ключевые кадры `rotation`, `position`,
`scale`, длительность и зацикливание. Molang-выражения не вычисляются, берутся
только числа.

Готовый файл пришлите — подключается одной строкой:

```tsx
<PlayerView ... animation={parseAnimations(json)[0]} />
```
